# Scoring Point System

A python tournament scoring system which has a simple user interface alloowing the user to manage teams, individual participants, events, results and the leaderboard.

## Features

- Add individual participants
- Add teams with team members
- Register participants for events
- Enter tournament results
- Display a leaderboard ranked by points
- Validation for incorrect data
- Limits the number of teams and individual participants

## Technologies used

- Python
- PyCharm

 correct data is entered.

## Project requirments
- Allows one event only entry
- Includes 5 events
- Produces a leaderboard
- Team and individual entries are accepted
- Points awarded based on position
- Maximum 20 individual participants
- Maximum 4 teams

# How it works
The user is presented with a menu where they can select different options. For example, the user can select option 2 to
add an individual participant. The individual participant is then added to the system, and the user can proceed with
another option.The program also includes an exit option, allowing the user to end the program.
